Toutes les autres pièces utilisent la bibliothèque 3D standard de KiCad 10 (`${KICAD10_3DMODEL_DIR}`).
Les embases JST NH (J3, J4, J5, J14) n'ont pas de modèle 3D ici : KiCad les signale comme manquants, sans effet sur les Gerbers.
